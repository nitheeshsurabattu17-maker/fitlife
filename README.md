# Fitlife Gym Guntur

The official web application for **FITLIFE GYM GUNTUR** — Guntur's premier fitness, Olympic strength training, cardio deck, personalized coaching by Chakri & Jani, and luxury sauna center situated at 3rd Floor, Phoenix Padmavathi Building, Koritepadu Main Road, Opp. LVR Club, Lakshmipuram, Guntur.

## Framework & Technology Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite (listening on `0.0.0.0:3000`)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Features**:
  - PulseFit floating capsule header with mobile drawer
  - Hero with athlete highlight and glowing orbital arc
  - Facility zones breakdown (Olympic Strength, Cardio Deck, 1-on-1 PT, Functional/CrossFit, Group/Zumba, Thermal Sauna)
  - Daily training schedule viewer (morning & evening shifts)
  - Coach mentorship profiles (Trainer Chakri & Trainer Jani)
  - Membership pricing plans (Monthly Starter, Quarterly Progress, Annual Elite)
  - Interactive membership inquiry form and instant WhatsApp integration
  - Filterable visual archive and photo lightbox
  - Contact details, verified address, and Google Maps embed

## Running the App
```bash
npm install
npm run dev
```
Dev server listens on `http://0.0.0.0:3000`.
